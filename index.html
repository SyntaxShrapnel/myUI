MX Bikes MNU editor

The editor reads and writes the plain-text .mnu dialog scripts directly. Every line you do not touch is written back byte-for-byte, so a saved file stays identical to the original except for the values you changed.

Rectangles

Rect values are floats from 0 to 1 of the UI surface, scaled by the aspect ratio in ui.ui (this mod: ratio 16:9). With a base of 1600 × 900:

X      = round(X1 * W)
Y      = round(Y1 * H)
Width  = round(X2 * W) - X
Height = round(Y2 * H) - Y

The pixel fields in the inspector are this formula in both directions: type 390 for X and the file gets 0.243750. Coordinates are relative to the dialog's own surface, which is the full screen.

Loading and saving

  • Open mod folder gives the editor write access, so Save writes straight back into the folder.
  • Open files (or dragging files onto the page) cannot write to disk, so Save downloads the file.
  • When the editor is served from this repo it tries to load true dark mode/ automatically; saving then downloads the file.

Keys

  • Drag inside an item to move it, drag a handle (or a corner) to resize.
  • Arrow keys nudge by 1 px, Shift + arrows by 10 px, Shift while dragging snaps to 10 px.
  • Ctrl/⌘ + Z undo, Ctrl/⌘ + Shift + Z redo, Ctrl/⌘ + S save.

The preview approximates the game's renderer: sprites are drawn from the TGA files, text uses a system font at the size stored in the file, and colours are the file's ARGB values.
